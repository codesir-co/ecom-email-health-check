# Competitor watch list

Used by the `competitor-analyst` agent. Public information only. Update it when the market changes.

Last checked: 2026-10-10 (changes are reported relative to this date; the next `plan-features` run updates it). Candidates not yet checked: `easy-wp-smtp`, `wp-mail-bank`.

| Plugin (WordPress.org slug) | Why we watch it |
|---|---|
| `wp-mail-smtp` | SMTP setup market leader; email log and alerts are paid features there |
| `fluent-smtp` | Free SMTP with a built-in log; strong with store owners |
| `post-smtp` | SMTP with log, resend and notifications |
| `wp-mail-logging` | Free email log; the standard for logging |
| `check-email` | Free email log and test email tool |

Also look at: other WooCommerce email tools (templates, customizers), WooCommerce's own email settings and Site Health, and deliverability checkers outside WordPress (SPF, DKIM and DMARC tools) for features users expect.

Not to be used as tags, names or copy. Never copy code, text or assets.
